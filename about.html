About CyberSaathi 🛡️

Your digital companion for a safer online world.

📘 About the Project

CyberSaathi is a web-based cybersecurity awareness project designed to help users understand common online threats and develop safer digital habits. It provides simple educational tools and guidance to make internet usage safer and more responsible.

🎯 Project Objectives

  • Spread awareness about cybersecurity and online safety.
  • Help users identify common signs of suspicious URLs.
  • Explain password strength and secure password practices.
  • Educate users about online scams and phishing attacks.
  • Test cybersecurity knowledge through an interactive quiz.
  • Guide users toward official cybercrime reporting resources.

⚙️ Technologies Used

CyberSaathi uses front-end web technologies to provide an interactive and responsive user experience.

HTML5 CSS3 JavaScript VS Code

HTML: Structures the web pages.
CSS: Controls the design, layout and responsive styling.
JavaScript: Adds interactivity, quiz scoring, URL checks, password feedback and theme switching.
VS Code: Used to write and manage the project code.

⚠️ Project Limitations

CyberSaathi is an educational awareness website, not a complete cybersecurity protection system. Its phishing checker uses heuristic rules and does not connect to a live threat database. Therefore, a low-risk result does not guarantee that a URL is safe, and a suspicious result does not prove that a URL is malicious.

The website does not directly report incidents to authorities, block cyberattacks or guarantee password security.
